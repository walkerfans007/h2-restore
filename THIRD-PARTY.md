# Third-party components

- **Rockbox 4.0**, AIGO Eros Q/K native target, unmodified `.rockbox` payload from the existing HIFIWALKER Restore project. Rockbox contributors; GPL version 2 or later, with component-specific notices retained in the payload. Project: https://www.rockbox.org/ . Release downloads: https://download.rockbox.org/release/4.0/ . Source repository: https://github.com/Rockbox/rockbox .
- **Rockbox Eros Q native bootloaders**, version `1a33d7990a-260203`, for hw1/hw2, hw3 and hw4. SPL and compressed bootloader bytes are reused unchanged from the Mac project's bundled archives; update containers are generated by that project's existing installer builder. Source revision: https://github.com/Rockbox/rockbox/tree/1a33d7990a . GPL version 2 or later. Installation reference: https://www.rockbox.org/wiki/AIGOErosQK .
- **Microsoft .NET / Windows Desktop runtime**, redistributed by `dotnet publish --self-contained` from Microsoft's runtime packs. Microsoft and contributors; MIT and component-specific licenses. See `Licenses/` for the notices supplied with the runtime packs. Sources: https://github.com/dotnet/runtime and https://github.com/dotnet/winforms .
- **HIFI WALKER original V2.3 firmware**, unmodified recovery payload from the existing Mac project. Its original catalog, provenance hashes and restoration hash checks are retained. It is not Rockbox and is not represented as GPL software.
- Product artwork: the H2 image supplied by the user, reused from the Mac app icon.

The Windows application uses the unmodified official **libusb 1.0.30 MinGW64 DLL** (LGPL-2.1-or-later). Its matching source archive and release archive are included under `ThirdPartySources`, and its license is in `Licenses/libusb-LGPL-2.1.txt`. Release: https://github.com/libusb/libusb/releases/tag/v1.0.30 . The library is dynamically loaded from `Assets/usb/libusb-1.0.dll`; it can be replaced by a compatible build. If replaced, update that entry in the editable `Assets/sha256.json` manifest to the replacement's SHA-256 so the integrity check accepts it.

The USB rescue decoder and boot sequence are adapted from Rockbox and the Mac port under GPL-2.0-or-later. The combined Windows application is provided under GPL-2.0-or-later; see `Licenses/Rockbox-COPYING.txt`. Complete Windows application source and build projects are in `ApplicationSource`. Build `ApplicationSource/App/HifiWalker.Windows.csproj` with the .NET 10 SDK, supplying the package's `Assets` folder as `ApplicationSource/Assets`. It does not bundle the Mac Swift/AppKit executable. Zadig is not bundled; its official website is linked for WinUSB driver setup.

Corresponding Rockbox source archives are included in `ThirdPartySources/`: the official `rockbox-source-4.0.7z` and the bootloader revision `1a33d7990a34e554084f0891823781e416c1ad3b` source snapshot. Their build tools and configuration scripts are retained in those archives. Rockbox GPL text is in `Licenses/Rockbox-COPYING.txt`.
